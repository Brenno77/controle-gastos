# Controle de Gastos (CRUD) - Python + SQLite

Projeto em Python (terminal) para registrar e gerenciar gastos usando SQLite.

## Funcionalidades
- Adicionar gasto (categoria, valor, data, descrição)
- Listar gastos
- Editar gasto (Enter mantém o valor atual)
- Remover gasto por ID

## Tecnologias
- Python 3
- SQLite (`sqlite3`)
